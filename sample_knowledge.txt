# Gemini CLI 完全ガイド

## 概要と開発背景

Gemini CLIは、Googleによって開発されたコマンドラインインターフェース（CLI）ツールです。
Googleのエンジニアリングチームが、開発者の生産性向上を目的として設計しました。
ターミナルから直接、GoogleのGeminiファミリーの生成AIモデルと対話できる点が特徴です。
2024年にリリースされ、オープンソースとして公開されています。
特にソフトウェア開発者やデータサイエンティストを主なターゲットとしており、
開発ワークフローを中断することなくAIの支援を受けられるように設計されています。

## 主な機能

Gemini CLIには以下の主要機能が搭載されています。

**コード生成**: 自然言語の指示からPython、JavaScript、TypeScriptなど多くの言語のコードを自動生成します。
関数の実装やクラスの設計、テストコードの生成にも対応しています。

**質問応答**: 技術的な質問に対して、ドキュメントや知識ベースを参照しながら正確な回答を返します。
プログラミングの疑問からアーキテクチャの相談まで幅広く対応します。

**テキスト要約**: 長いドキュメント、ログファイル、コードの差分などを簡潔に要約します。
Pull Requestの説明文やリリースノートの自動生成にも活用できます。

**コードベースの理解**: 複数ファイルにまたがる大規模なコードベースを解析し、
構造や依存関係を説明します。新しいプロジェクトへの参加時に特に役立ちます。

**エージェント機能**: シェルのようにコマンドを連続して実行し、
複雑なタスクを自律的にこなすエージェントとして動作します。
ファイルの作成・編集・削除、コマンドの実行なども指示できます。

## インストール方法

Gemini CLIのインストールは非常に簡単です。
Node.js 18以上がインストールされている環境で以下のコマンドを実行します。

```
npm install -g @google/generative-ai-cli
```

インストール後、以下のコマンドで正常にインストールされたか確認できます。

```
gemini --version
```

初回起動時にはGoogle アカウントでの認証が求められます。
`gemini auth login` コマンドを実行し、ブラウザで認証を完了してください。
認証情報はローカルに安全に保存されます。

## 対応環境と動作要件

Gemini CLIは主要なオペレーティングシステムに対応しています。

- **Windows**: Windows 10以降（WSL2推奨）
- **macOS**: macOS 12 Monterey以降
- **Linux**: Ubuntu 20.04以降、Debian、Fedoraなど主要ディストリビューション

動作に必要なスペックは以下の通りです。
Node.js 18以上、メモリ4GB以上、インターネット接続が必要です。
オフライン環境では利用できません。

## 料金体系

Gemini CLIの基本的な利用は無料ですが、APIの利用量によって料金が発生します。
無料枠として、1日あたり60リクエスト、1分あたり10リクエストが提供されています。
それを超える場合はGoogle Cloud Platformのプロジェクトに紐付けて従量課金で利用します。
詳細な料金はGoogle Cloud Platformの料金ページを参照してください。
企業向けの大量利用には、エンタープライズプランも用意されています。
